# MAK Marketplace

MAK Marketplace (HeiCode Market) is Heicode's catalog and delivery platform for AI capabilities. You can browse Skills and MCP tools, acquire entitlements through your HeiCode Manager identity, and deploy policy-approved capabilities to a Sub Agent or Swarm.

- Marketplace: [https://marketplace.heicode.cc/](https://marketplace.heicode.cc/)
- API contract: [https://marketplace-api.heicode.cc/openapi.json](https://marketplace-api.heicode.cc/openapi.json)
- Detailed workflow and current limitations: [MAK Marketplace guide](/docs/mak-market/overview)

> **The marketplace is currently a controlled beta.** Catalog browsing, HM sign-in, free acquisition, the balance ledger, and deployment records are available. End-to-end runtime delivery is still being accepted per capability kind. Real top-ups, third-party payments, refunds, publisher settlement, and credential-bearing MCP tools are not generally available.
