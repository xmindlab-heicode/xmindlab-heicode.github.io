# MAK Marketplace

MAK Marketplace (HeiCode Market) provides a unified experience for discovering, enabling, and managing Skills and MCP tools, so teams can equip their Agents with authorized expertise and external tools.

Enabled capabilities sync to your personal or organization capability catalog in HeiCode Manager (HM), where organization policy, approvals, and credential checks are enforced. When you start a single Agent, an Agent Team, or a Swarm, you then select the capabilities you need for that run.

- Marketplace: [https://marketplace.heicode.cc/](https://marketplace.heicode.cc/)
- Detailed workflow and boundaries: [MAK Marketplace guide](/docs/mak-market/overview)
