# MAK 市场

MAK 市场（HeiCode Market）提供统一的 Skill 与 MCP 发现、启用和管理体验，让团队能够为 Agent 配置经过授权的专业能力与外部工具。

启用后的能力会同步到 HeiCode Manager（HM）的个人或组织能力目录，由 HM 执行组织策略、审批和凭据检查；启动单 Agent、Agent Team 或 Swarm 时，再选择本次需要的能力。

- 市场入口：[https://marketplace.heicode.cc/](https://marketplace.heicode.cc/)
- 详细流程与能力边界：[MAK 市场说明](/zh/docs/mak-market/overview)
