# MAK 市场

MAK 市场（HeiCode Market）是 Heicode 的 AI 能力目录与交付平台。你可以浏览 Skill（技能）和 MCP（工具），通过 HeiCode Manager 身份获得能力权益，并将经过组织治理检查的能力部署到 Sub Agent 或 Swarm。

- 市场入口：[https://marketplace.heicode.cc/](https://marketplace.heicode.cc/)
- API 契约：[https://marketplace-api.heicode.cc/openapi.json](https://marketplace-api.heicode.cc/openapi.json)
- 详细操作与当前能力边界：[MAK 市场说明](/zh/docs/mak-market/overview)

> **当前为受控 Beta。** 目录浏览、HM 登录、免费能力获取、余额账本和部署记录已经提供；完整跨仓运行时链路仍按能力类型逐项验收。真实充值、第三方支付、退款、发布者结算和带长期凭据的 MCP 尚未正式开放。
