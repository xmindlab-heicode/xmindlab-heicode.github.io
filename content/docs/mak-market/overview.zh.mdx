# MAK 市场说明

MAK 市场是 Heicode 的技能与工具交易市场。你可以在市场中浏览、获取由官方与第三方发布者提供的 **Skill（技能）** 与 **MCP（工具）**，购买后将其绑定到 Sub Agent 上使用；也可以作为发布者上架自己的技能与工具并获得收益。

*本文描述的能力自 2026 年 8 月起随 MAK 市场首个版本提供。*

## 市场提供哪些商品

市场当前支持两类商品：

| 商品类型 | 说明 | 交付方式 |
|---|---|---|
| **Skill（技能）** | 封装好的能力包，例如代码评审、文档生成等 | 内联交付（inline_skill），技能内容随权益清单一并下发 |
| **MCP（工具）** | 遵循 MCP 协议的外部工具接入，例如代码托管、检索类工具 | 声明式交付，仅下发能力声明，不包含任何凭据 |

*注：Agent 模板的上架与交易尚未开放，当前版本仅支持 Skill 与 MCP 两类商品。*

## 从购买到在 Agent 中生效

购买完成后，商品不会自动出现在 Agent 里，而是经过一条固定的下发链路。理解这条链路有助于排查「买了但 Agent 用不上」的问题：

1. **结算生成权益** —— 结算完成后，市场为购买者创建一条处于生效状态的权益（Entitlement）。
2. **交付能力声明** —— 市场向 Heicode Manager 提供该权益对应的能力条目，使用稳定的治理标识，例如 `skill__code-review`、`mcp__github`。
3. **Manager 导入并按策略过滤** —— Manager 将条目导入所属组织的工具目录，并套用组织的允许／拒绝策略。被组织策略拒绝的条目不会下发。
4. **随部署下发** —— Manager 在向 Agent 管理侧发送部署配置时，携带经策略允许的技能与工具清单。
5. **运行时注入并回报** —— Agent 管理侧将配置注入运行时，Sub Agent 的健康状态会回报已加载的条目，以及结构化的加载失败原因。

也就是说：**购买只完成第一步，能否在 Agent 中生效还取决于所属组织的策略配置。** 如果购买后 Agent 中看不到该能力，优先检查组织的工具目录策略。

## 免费与付费商品的区别

| 商品定价 | 结算行为 |
|---|---|
| **免费** | 结算后立即授予权益，无需支付流程 |
| **付费** | 结算创建一笔待支付订单，经支付渠道完成支付后授予权益 |

付费订单的支付结果由支付渠道回调确认。回调经过校验且具备幂等性，同一笔订单**只会授予一份权益**，重复回调不会重复发放。

## MCP 商品的凭据须知

MCP 类商品的交付内容**从不包含组织凭据**。

购买 MCP 工具后，你获得的是该工具的能力声明与接入配置，而工具实际访问外部服务所需的凭据（如访问令牌）需要由**组织管理员单独绑定**。未完成凭据绑定的 MCP 工具，注入运行时后会以加载失败的形式回报，而不会静默使用空凭据。

## 我的库与权益

购买记录与可用能力分别在两处查看：

- **订单** —— 交易记录与支付状态，可查看单笔订单详情。
- **我的库** —— 已获得的权益清单，即当前可绑定到 Agent 的技能与工具。

权益与订单是两个不同概念：订单记录「买过什么」，权益记录「现在能用什么」。退款或下架会影响权益状态，但不会删除历史订单。

## 成为发布者

发布者可以上架自己的 Skill 与 MCP 商品。上架需要经过审核，商品状态按以下顺序流转：

| 状态 | 含义 |
|---|---|
| **草稿（draft）** | 已创建但未提交审核，仅发布者可见 |
| **待审核（pending）** | 已提交审核，等待平台审核结论 |
| **已发布（published）** | 审核通过，已在市场中对外可见并可购买 |

提交审核后请等待审核结论，审核期间商品不会对外可见。

发布者可在个人中心查看收益与结算情况。

## 个人中心与企业中心

市场提供两个管理入口：

- **个人中心** —— 账户信息、我的资产、权益、收藏、密钥、订单、发布管理、收益。
- **企业中心** —— 面向组织的市场管理入口，用于管理组织范围内的采购与授权。

## 常见问题

**买了技能，但 Sub Agent 里没有生效？**

按上文「从购买到在 Agent 中生效」的五步链路排查，最常见的原因是所属组织的工具目录策略未允许该条目。

**MCP 工具报加载失败？**

优先确认组织管理员是否已完成该工具的凭据绑定。市场交付不包含凭据，这是设计上的安全边界，不是缺陷。

**同一笔订单会不会重复扣费或重复发放权益？**

不会。支付回调具备幂等性，同一订单只授予一份权益。

**能上架 Agent 模板吗？**

当前版本不支持。市场仅支持 Skill 与 MCP 两类商品。
