# Manager 功能页面介绍

Heicode Manager 提供了多个功能页面，帮助你管理 Agent、监控任务、查看用量、配置策略和进行安全管理。本文介绍各功能页面的入口和用途。

## Agent 运行状态（/agent-status）

Agent 运行状态页面展示当前组织中所有 Agent 的运行情况，包括：

- 正在运行的 Agent 数量。
- 启动中的 Agent 数量。
- Agent 列表及其当前状态。
- 每个 Agent 的任务进度。

你可以在此页面快速了解整体 Agent 运行概况，发现异常时及时介入。

## 使用日志（/usage-logs）

使用日志页面记录每次模型调用的详细信息，包括：

- 调用时间。
- 消耗的 token 数量。
- 对应的任务和 Agent。
- 模型名称。
- 调用结果。

你可以按时间范围筛选日志，用于排查问题或分析用量趋势。

## 设备管理（/devices）

设备管理页面用于管理已登录 Heicode 客户端的设备。你可以：

- 查看当前已授权的设备列表。
- 查看每台设备的登录时间和最后活跃时间。
- 吊销不再使用或存在安全风险的设备。

设备管理与账号安全直接相关，建议定期检查并清理不再使用的设备。

## 模型准入与受管策略（/managed-policy）

受管策略页面用于配置模型使用策略，管理员可以：

- 设置允许使用的模型列表。
- 配置模型调用限制。
- 管理工具和 MCP 的启用状态。

## 工具与 MCP 目录（/tool-catalog）

工具与 MCP 目录页面展示当前可用的工具和 MCP Server，包括：

- 内置工具列表。
- 已连接的 MCP Server。
- 每个工具/MCP 的能力描述和权限要求。

你可以在此页面了解 Agent 可以调用哪些工具，以及各工具的权限范围。

## Agent PR 驾驶舱（/agent-pr-tasks）

Agent PR 驾驶舱用于集中查看和管理 Agent 创建的 Pull Request，包括：

- PR 列表及其状态（打开、已合并、已关闭）。
- 每个 PR 关联的任务和 Agent。
- PR 的审查状态。

此页面帮助团队跟踪 Agent 生成的代码变更，确保所有 PR 都经过适当的审查流程。

## 自建 Agent 模板

在部署 Agent 页面（/deploy-agent），除了使用 Heicode 提供的 19 种角色模板外，你还可以创建自定义 Agent 模板：

- 基于现有角色模板进行定制。
- 配置模板的技能、工具和默认权限。
- 保存模板供团队重复使用。

自定义模板适合团队有特定工作流需求时使用，可以避免每次部署都重新配置。

## 审计日志（/audit-logs）

审计日志页面记录所有关键操作，但访问有权限限制：

- **Owner / Admin / Auditor** 角色可以查看组织的完整审计记录。
- **普通 Member** 和个人用户无法访问此页面（返回 403）。

审计日志包含操作主体、操作类型、目标资源、时间和结果，用于合规审查和安全排查。
